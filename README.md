# 双人默契测试 · 纯前端 H5

> 15 道题，测出你们能对上几道。情侣版 / 朋友版 / 室友版三种关系，单文件无后端，零门槛分享。

## 运行

纯静态页面，无构建、无依赖。

- 直接双击 `index.html` 即可打开；
- 或在目录内起本地服务：`python -m http.server 8000`，访问 `http://localhost:8000`。

`audio/` 目录必须与 `index.html` 同级，否则背景音乐与音效不会播放。

## 目录结构

```
index.html                    全部页面（样式、脚本、题目、结果文案均内联）
audio/
├── bgm-couple.wav            情侣版主题 BGM（钢琴 + 风铃，循环）
├── bgm-friend.wav            朋友版主题 BGM（干净钢琴 + 合成器）
├── bgm-roommate.wav          室友版主题 BGM（木吉他 + 小打）
├── sfx-start.wav             进入页面
├── sfx-click.wav             选项点击
├── sfx-flip.wav              翻下一题
├── sfx-success.wav           复制成功 / 生成链接
├── sfx-welcome.wav           对方点开分享链接
├── sfx-report.wav            生成最终报告
└── sfx-theme.wav             切换关系主题
```

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 三种关系 | 情侣 / 朋友 / 室友，各有独立题库与主题配色 |
| 双人轮流 | 先由 A 作答，生成专属链接；B 点开后答题并自动比对 |
| 私密档案 | 10 题私人问题模块，双方填写后本地 AI 比对（启发式，无服务器） |
| 六维雷达 | SVG 六边形雷达图，自动映射低分区间，零值也保留区分度 |
| 错题清单 | 可折叠 / 展开，默认只显示数量标题 |
| 分享海报 | Canvas 750×1000 海报生成，长按保存 |
| 主题 BGM | 三种关系各配一首背景循环乐，默认开启，可手动关闭与调音量 |
| 全交互音效 | 点击、翻页、报告揭晓等关键节点均有专属短音效 |
| 裂变机制 | 「我填完发给别人猜」+「换我出题考回去」，URL 哈希全链路 |

## 部署

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main`、目录 `/ (root)`，保存即可。
- **Netlify / Vercel**：直接拖入本文件夹，无需构建命令。
- **自有服务器**：整体放到站点根目录。

## 说明

- 背景音乐默认打开，首次任意交互后自动播放（iOS 要求用户手势），音量滑块与开关状态记录在 `localStorage`。
- 测评结果仅供娱乐参考，不构成专业心理诊断或医疗建议。
- 题目与答案全在 URL 里，无需后端，链接即完整考卷。

## 上架素材

`marketing/` 目录下包含商品主图、详情图、15 字内标题、短描述与自动发货话术，可直接用于 itch.io / N 网等数字商品平台上架。
